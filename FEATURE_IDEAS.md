# Expense Tracker Feature Ideas

Use these as improvement prompts for the existing expense tracker website.

## 1. Month Switcher

Add a month selector to the dashboard so users can view previous months, not only the current month. The selected month should update totals, budget, charts, category summaries, and the recent expenses table.

## 2. Edit Expense

Add an edit option for each expense. Users should be able to update amount, category, description, and date without deleting and recreating the entry.

## 3. Search And Filters

Add search and filter controls for expenses. Support filtering by category, date range, amount range, and description text.

## 4. Recurring Expenses

Add recurring expenses for predictable payments like rent, subscriptions, gym, phone plan, and streaming services. Users should be able to create, view, pause, and delete recurring rules.

## 5. Category Budgets

Add separate monthly budgets per category, such as Food, Transport, Shopping, and Gym. Show each category's budget usage and warnings when it reaches 80% or 100%.

## 6. Better Insights

Add insight cards such as highest spending day, top category, average daily spend, projected month-end spend, and comparison with the previous month.

## 7. Export Data

Add export options so users can download expenses as CSV or Excel. Export should respect the selected month and active filters.

## 8. Import Data

Add CSV import so users can bulk add old expenses or migrate data from another tracker. Validate rows and show a preview before saving.

## 9. Authentication

Protect the dashboard when deployed publicly. Add a simple login, passcode, or auth provider so only the owner can view and manage expenses.
